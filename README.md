🚀 SmartHire – Recruitment Intelligence Platform

SmartHire is a responsive recruitment management web application designed to simplify candidate management and job recruitment. It helps recruiters manage job openings, register candidates, evaluate skill matches, track application statuses, and export candidate data.

✨ Features

- Dashboard: View recruitment statistics and activity.
- Job Management: Add, edit, and delete job openings.
- Candidate Management: Register and manage candidate profiles.
- Skill Matching: Calculate candidate skill-match percentages against job requirements.
- Application Tracking: Update candidate statuses, including Under Review, Shortlisted, and Rejected.
- Search and Filtering: Quickly find candidates and filter by application status.
- CSV Export: Export candidate information for further analysis.
- Responsive Design: Access the application on desktop and mobile devices.
- Local Storage: Save data in the browser for persistence between visits.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

⚙️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Start managing jobs and candidates!

🧠 How Skill Matching Works

SmartHire uses rule-based skill matching to compare candidate skills with the skills required for a job.

The match percentage is calculated based on the number of matching skills.

🎯 Project Objective

The objective of SmartHire is to demonstrate how web technologies can be used to build a recruitment management system with candidate tracking, skill matching, and data export capabilities.
